# NYRAFLOW — MONOCHROME VISUAL REDESIGN FOR REACT / ANTIGRAVITY

## Контекст

Нужно профессионально улучшить визуальную часть текущего сайта Nyraflow:

`https://myland-sooty.vercel.app/`

Проект уже собран на React и редактируется в Antigravity.

Цель — привести весь сайт к единой премиальной чёрно-белой визуальной системе, полностью убрать синий цвет и устранить заметную разницу между палитрой сайта и палитрой двух уже реализованных анимаций.

Это не новый сайт и не полный редизайн структуры.  
Нужно сохранить текущий контент, порядок смысловых блоков, ссылки, формы и бизнес-логику, но профессионально переработать визуальную систему, композицию, типографику, поверхности, карточки, кнопки, изображения и переходы между секциями.

# КРИТИЧЕСКИ ВАЖНО: ДВЕ АНИМАЦИИ НЕ ТРОГАТЬ

На сайте уже существуют две разные анимации:

## 1. Полноэкранная hero-анимация

- находится в hero-секции;
- занимает весь первый экран;
- состоит из нескольких сцен;
- меняет композицию, фон и цвет текста;
- проигрывается автоматически;
- повторяется циклически.

## 2. Анимация «Мы создаём» перед блоком цен

- находится отдельно перед ценами;
- не является hero;
- содержит статичный русский текст `Мы создаём`;
- рядом циклически меняются английские направления;
- является обычной секцией страницы.

## Запрещено менять в обеих анимациях

Не менять:

- тексты;
- порядок сцен;
- тайминги;
- длительность;
- easing;
- state machine;
- цикличность;
- поведение при паузе;
- механику появления элементов;
- DOM-структуру без крайней необходимости;
- расположение анимаций на странице;
- логику React;
- мобильную механику;
- hover и interaction logic, если они уже работают;
- ссылки и CTA;
- последовательность dark/light сцен hero.

## Что разрешено изменить в анимациях

Разрешено изменить **только цветовые токены и внешние обёртки**, если это необходимо для единства сайта:

- заменить старый синий или синевато-чёрный на утверждённый нейтральный чёрный;
- привести белые сцены к единому off-white;
- привести цвет текста к общим токенам;
- убрать цветной glow;
- убрать синие тени;
- синхронизировать фон соседних секций;
- исправить видимый шов между анимацией и остальным сайтом.

Смысл: **не переделывать анимации, а встроить их в единую палитру сайта**.

Hero и секция перед ценами должны остаться разными независимыми компонентами.  
Не объединять их и не связывать их таймеры.

# СИНХРОНИЗАЦИЯ С ДВУМЯ АНИМАЦИЯМИ

## Hero

Hero использует:

```text
black: #000000
light: #F5F5F2
dark text: #101114
light text: #FFFFFF
```

Эти же значения должны использовать все остальные секции.

Если текущий сайт использует тёмно-синий, graphite-blue или близкий оттенок рядом с hero:

- заменить его на `#000000`;
- убрать видимый цветовой шов;
- убрать промежуточную синюю полосу;
- убрать другой оттенок чёрного, который визуально конфликтует с hero.

Первая секция после hero должна начинаться так, чтобы переход выглядел намеренным.

Предпочтительно:

- финальная hero-сцена остаётся чёрной;
- следующая секция начинается с того же `#000000`;
- между ними нет лишнего margin, border, gradient или отличающегося background;
- переход к светлой части происходит уже внутри следующего смыслового ритма.

## Анимация перед ценами

Для внешней обёртки секции использовать:

```text
background: #000000
primary text: #FFFFFF
secondary text: rgba(255,255,255,0.60)
```

Следующий блок цен может переходить в `#F5F5F2`, но переход должен быть намеренным:

- без синей прослойки;
- без несовпадающих чёрных оттенков;
- без случайного закруглённого контейнера;
- либо чистый резкий editorial cut;
- либо крупная светлая плоскость, начинающаяся сразу после анимации.

Не менять механику текста `Мы создаём`.

# ТИПОГРАФИКА

Сначала изучи уже используемый шрифт и сохрани его, если он подходит.

Не подключай случайный новый шрифт только ради визуального эффекта.

Нужно создать чёткую типографическую шкалу.

Примерные ориентиры:

```css
--font-display-xl: clamp(52px, 7vw, 128px);
--font-display-lg: clamp(42px, 5.4vw, 92px);
--font-heading-lg: clamp(34px, 4vw, 68px);
--font-heading-md: clamp(26px, 2.8vw, 46px);
--font-body-lg: clamp(18px, 1.4vw, 24px);
--font-body: 16px;
--font-caption: 12px;
```

Требования:

- меньше случайных размеров;
- не использовать слишком много uppercase;
- uppercase допустим для маленьких labels;
- заголовки должны быть крупнее и спокойнее;
- уменьшить визуальную плотность текста;
- ограничить ширину длинных абзацев;
- body text: приблизительно `55–72ch`;
- аккуратно настроить line-height;
- использовать letter-spacing только осознанно.

Русская типографика:

- проверить переносы;
- не оставлять короткие предлоги в конце строки, если это легко исправить;
- использовать неразрывные пробелы там, где это важно;
- не ломать существующие тексты и смысл.

# КАРТОЧКИ И ПОВЕРХНОСТИ

Текущая система не должна выглядеть как набор одинаковых SaaS-карточек.

## Использовать

- плоские поверхности;
- тонкие линии;
- крупные блоки;
- асимметричную, но контролируемую сетку;
- инверсию чёрного и белого;

## Не использовать

- синие карточки;
- цветные glow;
- glassmorphism;
- backdrop blur без необходимости;
- большие мягкие тени;
- одинаковый border-radius на всех элементах;
- карточку внутри карточки;
- слишком много pills;
- декоративные gradients;
- неон.

Рекомендуемый radius:

```text
0–16px
```

Не использовать чрезмерные `24–40px` на каждом контейнере.
