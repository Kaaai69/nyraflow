## React / Antigravity — strict implementation prompt

## Текущая версия

Работать с текущим сайтом:

`https://myland-sooty.vercel.app/`

Проект уже реализован на React.

Предыдущая попытка улучшения визуальной иерархии считается неудачной: в большинстве секций были добавлены только тонкие линии и разделители, но сама композиция, поверхности и визуальная группировка почти не изменились.

## Главная задача

Провести **реальную структурную переработку визуальной части сайта**, а не косметическую правку borders.

После выполнения:

- секции должны заметно отличаться друг от друга;
- смысловые группы должны считываться без необходимости читать весь текст;
- текст не должен выглядеть одним непрерывным потоком;
- должны появиться выраженные поверхности, карточки, инверсии, крупные блоки и разная сетка;
- концепты должны стать полноценным раскрывающимся каталогом;
- сайт должен остаться строго чёрно-белым;
- две существующие анимации нельзя менять.

# ПАЛИТРА И УРОВНИ ПОВЕРХНОСТЕЙ

Создать минимум три уровня светлых и три уровня тёмных поверхностей:

```css
:root {
  --black: #000000;
  --dark-1: #0B0B0B;
  --dark-2: #151515;

  --paper: #F3F3EF;
  --paper-2: #E7E7E1;
  --white: #FFFFFF;

  --ink: #101114;

  --text-light: #FFFFFF;
  --text-light-muted: rgba(255,255,255,.58);

  --text-dark: #101114;
  --text-dark-muted: rgba(16,17,20,.58);

  --border-light: rgba(255,255,255,.16);
  --border-dark: rgba(16,17,20,.15);
}
```

## Обязательное правило

Карточка не должна иметь тот же фон, что и секция.

Примеры:

```text
секция #F3F3EF → карточки #FFFFFF
секция #000000 → карточки #151515
секция #E7E7E1 → карточка #101114
```

Именно разница поверхностей должна создавать группировку, а линии использовать только как дополнение.
