# План реализации главной страницы

> Для исполнителей: при реализации обязательно использовать `superpowers:subagent-driven-development` или `superpowers:executing-plans`. Работу вести небольшими проверяемыми задачами. После каждой задачи сравнивать результат с проектным брифом и эталоном Spline. Этот документ не содержит код приложения, потому что текущий этап ограничен планированием.

**Цель:** собрать светлый премиальный сайт digital-команды вокруг неизменяемого Spline-героя, реальных кейсов, услуг, команды, процесса, FAQ и финальной конверсии.

**Архитектура:** предполагается Next.js App Router, поскольку предоставлен импорт `@splinetool/react-spline/next`. Статические секции должны оставаться Server Components, а motion, FAQ и форма изолируются в небольших Client Components. Контент хранится отдельно от представления, чтобы можно было заменить допущения подтверждёнными фактами без перестройки страницы.

**Предполагаемый стек:** Next.js, React, TypeScript, `@splinetool/react-spline`, `next/image`, `next/font`, CSS variables или существующая система стилей, Motion только при отсутствии эквивалентного решения в текущем проекте, Playwright для визуальных и e2e-проверок.

## Глобальные ограничения

- Не менять Spline-сцену, URL, импорт, компоновку, тексты, CTA, навигацию и интерактивность.
- Не писать вымышленные кейсы, метрики, отзывы, цены, сроки и контакты.
- Сохранять одну светлую тему и один синий акцент.
- Разрешены две CTA в герое и один повторяемый основной CTA ниже.
- Разрешён один блок из трёх равных карточек доверия.
- Все остальные секции используют разные композиции.
- При reduced motion вся дополнительная анимация ниже Spline отключается или упрощается.
- Реализация портфолио не начинается до получения реальных case assets.
- Текущий репозиторий неполный: в рабочей папке отсутствует приложение.
