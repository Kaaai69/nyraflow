# Волновой фон и анимация карточек

**Дата:** 2026-08-20
**Ветка:** `feat/wave-bg-and-card-motion`
**База отката:** `main` @ 46ffb9e

## Задача

Перенести на сайт три вещи из референсного лендинга (`index.html`, AETHER):
волнообразный фон, появление карточек по скроллу и подсветку карточки под
курсором. Чёрно-белая стилистика сайта сохраняется без изменений: никаких
новых цветов, только белый, чёрный и градации серого.

## Что меняется

### 1. Фон: `components/BackgroundWaves.tsx` (новый)

WebGL-шейдер во весь экран заменяет canvas-2D поле частиц.

Механика взята из референса: fbm-шум с domain warping (шум, искажающий
координаты другого шума) — он и даёт непрерывно перетекающие волны.

Отличия от референса:
- палитра строго монохромная: база `#000`, гребни до `rgba(255,255,255,.10)`;
- убраны звёзды, метеоры и warp-эффект по клику;
- добавлено мелкое зерно против бандинга на тёмных градиентах.

Реакции: время (непрерывное течение), курсор (параллакс + мягкое свечение),
скролл (сдвиг волн по вертикали).

Деградация:
- нет WebGL → статичный радиальный градиент на `<canvas>`;
- `prefers-reduced-motion` → один статичный кадр, RAF не запускается;
- вкладка неактивна → RAF останавливается.

`BackgroundFlowField.tsx` остаётся в репозитории неиспользуемым, чтобы откат
фона был правкой одной строки в `app/page.tsx`.

### 2. Появление по скроллу: `components/ScrollRevealSection.tsx`

Параметры приводятся к референсным (`gsap.to(.reveal)`):

| Параметр | Было | Стало |
|---|---|---|
| ход по Y | 24-32px | 50px |
| длительность | 0.75s | 1.1s |
| ease | `[0.22, 1, 0.36, 1]` | `[0.165, 0.84, 0.44, 1]` (power3.out) |
| повтор | `once: false` | `once: true` |
| порог | `amount: 0.15` | `margin: "0px 0px -14% 0px"` (= `top 86%`) |

Ступенчатость (stagger) в сетках сохраняется — в референсе её нет только
потому, что там каждая карточка триггерится отдельно.

### 3. Наведение: `MotionCard` / `MotionSlab`

Внутрь обёрток добавляется слой с двумя эффектами:

- **Пятно света** — радиальный градиент `rgba(255,255,255,.10)` → прозрачный
  к 65%, следует за курсором через CSS-переменные `--mx` / `--my`,
  проявляется за 500ms. Клипуется собственным `border-radius`, поэтому
  `overflow-hidden` не нужен и ничего не обрезает.
- **Наклон** — `rotateX` до -8°, `rotateY` до 10° (значения референса), на
  пружине framer-motion, возврат в ноль при уходе курсора.

Наклон включается только для «коробочных» карточек — тарифы, слабы услуг,
команда, метрики, выгоды. Блоки, свёрстанные как строки или колонки списка
(шаги процесса, credibility, пункты Starter), получают только пятно света:
наклон строки во всю ширину экрана выглядит сломанно.

Оба эффекта работают только при `(hover: hover) and (pointer: fine)` и
отключаются при `prefers-reduced-motion`.

## Откат
