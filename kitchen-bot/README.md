# Демо-бот «Кухни на заказ»

Telegram-бот, который ведёт клиента мебельщика: уточняет параметры кухни по одному вопросу, присылает ориентировочную вилку цены и записывает на бесплатный замер. Спецификация лежит в `../SPEC_kitchen_bot.md`.

| Файл | Что внутри |
|---|---|
| `config.json` | прайс, справка о компании, приветствие. Единственное, что меняется под конкретного мебельщика |
| `core.py` | ядро без Telegram: состояние, промпт, слияние полей, расчёт вилки, выжимка менеджеру |
| `llm.py` | клиент OpenAI-совместимого API (по умолчанию Polza AI) |
| `storage.py` | сессии и полные переписки в `data/` |
| `telegram_bot.py` | транспорт: `/start`, `/reset`, текст, доставка менеджеру |
| `scenarios.py` | прогон сценариев «попробуй сломать» на живой нейросети |

Цену считает код по `config.json`. Нейросеть только извлекает данные и ведёт разговор. Если она всё же напишет сумму, ответ перегенерируется, а при повторе фраза с суммой вырезается.

## Модель

`anthropic/claude-haiku-5.5` через Polza AI: 11,75 ₽ за 1M входных токенов и 58,75 ₽ за 1M выходных. Одно сообщение клиента — один вызов, около 3–4 тыс. токенов на входе, то есть примерно 5 копеек. Дешёвая запасная модель: `deepseek/deepseek-v4.1-flash` (`LLM_MODEL=…` в `.env`).

## Локально

```bash
cp .env.example .env   # вписать TELEGRAM_TOKEN и LLM_API_KEY
pip install -r requirements.txt pytest
pytest tests              # логика без сети
python scenarios.py       # сценарии на живой модели
python telegram_bot.py
```

## Сервер

Бот работает через long polling, поэтому домен и HTTPS ему не нужны. Он живёт отдельно от стека nyraflow:

```bash
# на сервере, в /opt/kitchen-bot
mkdir -p data && chown 1001 data    # контейнер пишет от uid 1001
docker compose up -d --build
docker compose logs -f bot
```

Переписки лежат в `data/transcripts/<chat_id>.jsonl`. Их стоит читать, чтобы находить, где бот спотыкается, и править промпт в `core.build_system_prompt`.
