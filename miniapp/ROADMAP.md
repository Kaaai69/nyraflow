# nyraflow desk — маршрут до цели

Живой документ: отмечаем сделанное, уточняем следующее. Обновляется по ходу.

## Цель

Telegram Mini App, который закрывает пресейл и ведение проектов студии, и в
котором каждое значимое действие порождает событие для n8n. Не витрина —
рабочий инструмент, который окупается, когда пойдёт поток клиентов.

Три режима одного приложения:

1. **Пресейл** — бриф, AI-разбор задачи, заявка. Работает без клиентов, с первого дня.
2. **Кабинет клиента** — проект по пяти этапам студии, задачи, согласования, счета.
3. **Админ** — лента заявок, перевод этапов, апдейты клиенту.
