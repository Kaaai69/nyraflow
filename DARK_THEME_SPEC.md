# 🎨 Dark Mode Specification — nyraflow

**Цель для AI-ассистента (Anti-gravity / Cursor / Cursor AI):** Перевести лендинг nyraflow на тёмную монохромную эстетику, создать новую ветку и подготовить проект к деплою на Vercel.

## 1. Настройка окружения и Деплой
1. **Изоляция:** Создай новую ветку для обновления дизайна: 
   `git checkout -b feature/dark-theme-update`
2. **Разработка:** Все тесты проводи локально через `npm run dev`.
3. **Деплой на Vercel:** После утверждения локальной версии, сделай commit, push в репозиторий и инициируй деплой на Vercel (через Vercel CLI `vercel --prod` или через слияние с main).

## 2. Цветовая палитра и системные стили (Tailwind CSS)
Внедри следующие токены по всему проекту:
- **Main Background**: Заменить все светлые фоны на `#0B0C0E` (`bg-[#0B0C0E]`).
- **Card Surface / Glassmorphism**: Карточки ценностей, тарифов и услуг перевести в стекло: `bg-[#16181D]/60 backdrop-blur-md border border-white/10`. При hover добавлять `border-white/20`.
- **Primary Text**: Заменить темный текст (заголовки, основной текст) на `#F1F5F9` (`text-[#F1F5F9]`).
- **Muted Text**: Заменить серый текст (описания, подзаголовки) на `#94A3B8` (`text-[#94A3B8]`).
- **Акценты и Кнопки**: Кнопки сделать контрастными со свечением: `bg-white text-[#0B0C0E] hover:bg-[#E2E8F0] shadow-[0_0_20px_rgba(226,232,240,0.15)]`.
